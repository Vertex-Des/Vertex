What is Vertex?

Most students only use Desmos to double-check work. We teach it as a primary problem-solving tool: graph an intersection instead of solving a system by hand, run a regression instead of guessing an equation, read a stats list instead of computing standard deviation by formula. Every problem on Vertex is organized by SAT math domain, comes with a live Desmos calculator you can play with, and a real step-by-step walkthrough when you get stuck.

Organized by SAT domain

Algebra, Advanced Math, Problem-Solving & Data Analysis, and Geometry & Trigonometry — several Hard-difficulty problems each.

Real, interactive Desmos

Every walkthrough includes a live embedded calculator you can actually manipulate, not just a screenshot.

Self-check with a timer

Type your answer and check it instantly. Each problem quietly times how long you take to answer.

A note on scope: Vertex is dedicated to SAT math problems that can be solved with Desmos — not every SAT problem can be. We focus on the ones where a graphing calculator genuinely changes how fast and how confidently you can solve them.
