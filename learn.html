The tools you need

Graphing equations

Type any equation into an expression line — y=2x+3 — and Desmos plots it instantly. Two equations plotted together show their intersection point, which is the solution to a system of equations.

Sliders

Type an equation with an extra constant, like y=ax+3, and Desmos offers to add a slider for a. Drag it to see how changing that constant reshapes the graph — useful for exploring quadratics and transformations.

Regressions

Add a table (click the + and choose Table), and enter your data — Desmos labels the columns x1 and y1 automatically. Then add a new expression: y1 ~ mx1+b. Desmos fits the best-fit line and reports the values of m and b directly — swap in y1 ~ ax12+bx1+c for a quadratic fit.

Statistics on a list

Enter a list using curly braces, like L={2,4,4,6,8}. Then on new lines, type mean(L), median(L), or stdev(L) — Desmos computes each statistic instantly, no formula required.

How to build up your skills

Work through Practice in this order and each Desmos tool will click before you need the next one:

  1. Start with systems of equations. Graph two lines and read the intersection point — this alone replaces most of Algebra's "solve for x and y" problems.
  2. Move to regressions. Once you're comfortable graphing, let Desmos fit a line or curve to a table of points instead of solving for constants by hand.
  3. Finish with chained ratio/percentage problems. These look intimidating in words ("a is 500% of b, and b is 25% of c...") but become simple once you set them up as equations and let Desmos solve.
